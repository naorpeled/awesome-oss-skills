# Maintainer triage and review

## Who this is for

Maintainers who need help with recurring repository health work.

## Primary inputs

- issue templates
- pull request templates
- `README.md`
- `CONTRIBUTING.md`
- `DEVELOPER.md` or `docs/development.md`
- labels, discussion norms, and repository conventions

## What this skill should do

### Ongoing maintainer workflows

- triage new issues and request missing details
- classify issues into bug, feature, question, or docs work
- review pull requests against documented contribution and testing rules
- detect documentation drift between repository behavior and repo docs

### One-off maintainer workflows

- improve contribution documentation when common confusion appears
- strengthen PR or issue templates
- run onboarding audits to see whether new developers can get started quickly

## Typical output

- triage recommendations and follow-up questions
- review notes grounded in repo conventions
- a list of documentation improvements
- suggested maintainer actions for one-off and ongoing work

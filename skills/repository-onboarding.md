# Repository onboarding

## Who this is for

New or returning contributors who need a fast overview of how a repository
works.

## Primary inputs

- `README.md`
- `CONTRIBUTING.md`
- `DEVELOPER.md` or `docs/development.md`
- `CODE_OF_CONDUCT.md`
- `SECURITY.md`
- issue and pull request templates

## What this skill should do

- summarize the repository's purpose and current contribution opportunities
- identify setup, build, test, and lint instructions
- explain contribution expectations and review workflow
- point to the docs that a contributor should read next

## Typical output

- a short onboarding summary
- a checklist of first setup steps
- a list of repository norms and expectations
- a map of the most relevant files for the contributor's task

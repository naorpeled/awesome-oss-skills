# Local development bootstrap

## Who this is for

Contributors who want to get a repository running locally without manually
searching through documentation.

## Primary inputs

- `README.md`
- `CONTRIBUTING.md`
- `DEVELOPER.md` or `docs/development.md`
- tool configuration files such as `package.json`, `pyproject.toml`, `go.mod`,
  `Cargo.toml`, or `Makefile`

## What this skill should do

- extract install and environment setup steps
- identify the project's build, test, and lint commands
- call out missing prerequisites or platform-specific notes
- highlight any mismatch between documentation and configuration files

## Typical output

- a clean setup checklist
- commands to run in order
- a short list of gaps or confusing documentation that should be improved

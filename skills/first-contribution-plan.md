# First contribution plan

## Who this is for

Contributors preparing a one-off change such as a docs fix, test update, or
small bug fix.

## Primary inputs

- issue text or a requested task
- `README.md`
- `CONTRIBUTING.md`
- relevant code or docs files
- issue labels or templates when available

## What this skill should do

- turn a task into a small, concrete plan
- identify the files and checks most likely to matter
- keep the proposed scope friendly for a first pull request
- verify that the work matches documented contribution expectations

## Typical output

- a minimal implementation plan
- the likely files to edit
- the validation steps to run
- a pull-request-readiness checklist
